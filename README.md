# Књиговодство Тренер

Апликација за вјежбу рачуноводства (економска школа). Један HTML фајл, ради и без интернета.

- `index.html` — апликација (отвара се у прегледачу)
- `src/razred2.js`, `src/razred2.css` — извор дијела за 2. разред
- `build.py` — убацује `src/` у `index.html` (покренути послије сваке измјене у `src/`)

## 1. разред
Евиденција материјала (FIFO, просјечна, планска) и обавеза према добављачима.

## 2. разред
- **I Пословне књиге двојног књиговодства** (уџбеник стр. 9–24): теорија, 14 питања,
  брзо контирање, задаци из уџбеника (примјер „Дрина“, бр. 1, 2, 3, 5а, 5б) и
  неограничене нове вјежбе, плус додатни примјер „Козара“. Сваки задатак: почетни биланс → дневник → главна књига /
  пробни биланс → закључак и крајњи биланс, са објашњењем сваког корака.
- Отварање књига: преко конта 7000 (као у свесци) или директно (као у уџбенику).
- Задатак бр. 4 („Маркет“) чека провјеру: у промјени 7 продавница продаје више робе него што има.

## Инсталација на телефон
Апликација је PWA (`manifest.webmanifest`, `sw.js`, `icons/`): отвори линк у Chrome-у → „Додај на почетни екран“.
Кад има интернета, увијек учитава најновију верзију; без интернета ради из кеша.

## Преглед за родитеље
Дугме „👪 За родитеље“ (PIN): активно вријеме по данима, резултати и посљедње активности.
Подаци се чувају само на уређају.
